# Concierge Audit OS — Agent Skills & Tool Specifications

## 1. `calculate_revenue_gap`
Computes financial performance, district benchmark gaps, and leakages.

## 2. `render_weasyprint_pdf`
Compiles an audit payload into a strictly formatted single-page A4 PDF using Jinja2 and WeasyPrint.

## 3. `generate_ota_copy`
Uses the Direct-Response OTA copywriting engine to generate title variants, structured descriptions, and a photo prioritization matrix.

## 4. `sync_channel_manager`
Dispatches approved listing optimizations directly to the specified Channel Manager / PMS API.
